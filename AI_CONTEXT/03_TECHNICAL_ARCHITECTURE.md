# Technical Architecture

## Prinsip
- Audit repository sebelum mengubah arsitektur.
- Ikuti pola yang sudah ada jika sehat; jangan membuat manager/script baru hanya demi nama.
- Pisahkan tanggung jawab, hindari ketergantungan silang yang tidak perlu.
- Gunakan solusi sederhana, efisien, dan sesuai Unity 2D serta target perangkat rendah.

## Area tanggung jawab (panduan, bukan kewajiban satu kelas per sistem)
- Game/day flow: state permainan, hari, tidur, ending.
- Resource: stok, konsumsi, produksi, validasi perubahan.
- Player: movement, animasi, collision, interaksi.
- Suit: status suit dan Suit Oxygen outdoor.
- Farming: plot, penyiraman, tahap Potato, panen.
- Machines: purifier dan oxygen generator.
- Solar: produksi Energy dan kondisi panel.
- TARS: pemicu pesan/pengingat.
- Save: progres yang perlu dipertahankan.

## Audit teknis wajib
Periksa `ProjectSettings/ProjectVersion.txt`, `Packages/manifest.json`, struktur `Assets/`, scene, prefab, script, `.meta`, Input System, physics, dan Animator sebelum memberi instruksi yang bergantung padanya.

## Implementasi saat ini (2026-11-15, commit `e6feb586`)
- **Versi:** Unity 6000.6.8f1, URP 17.6.0, Input System 1.20.1 (Active Input Handling = Both), Cinemachine 6.6.0, uGUI 2.6.0. [Repo]
- **Input:** kode memakai API lama (`Input.GetAxisRaw`, `Input.GetKeyDown`). Aman karena mode Both.
- **Interaksi:** pola `IInteractable` + `InteractionDetector` (Player) + `InteractionPromptUI`. Objek baru (bed, mesin, plot) cukup mengimplementasikan `IInteractable`; detector tidak perlu diubah. `IInteractable` tidak punya interaksi tahan; `IceDeposit` mengatur sendiri timer pengumpulan (E ditekan sekali, pemain dikunci lewat `PlayerMovement.MovementEnabled`).
- **Dialog input (2026-11-15):** lanjut/tutup dengan E, Spasi, atau klik mouse kiri di mana saja (`clickAnywhereToAdvance`); tombol Tutup opsional (`closeButton`) menutup langsung. Klik pada tombol Tutup tidak dihitung ganda (dicek lewat `RectTransformUtility`). EventSystem memakai `InputSystemUIInputModule` (Button bekerja). Tombol Tutup dibuat oleh menu `Mars > Setup Dialogue and Prompt UI`. [Repo, belum dites di Unity]
- **Dialog tutorial (2026-11-28):** `DialogueUI.Show(..., TutorialDialogueInfo?)`; bila info diisi, `TutorialDialogueSkin` (kartu tengah atas) menggantikan kotak bawah. Info dikirim `TutorialManager` lewat `TARSSystem.Announce`. Input/`IsOpen`/callback tetap di `DialogueUI`.
- **Dialog:** `DialogueUI` hanya tampilan. Pemanggil mengirim nama pembicara, baris teks, dan callback selesai. TARS memakai teks tetap dari Inspector (sesuai GDD: predefined, tanpa AI generatif).
- **TARS:** `TarsWanderer` memakai Rigidbody2D Dynamic agar bertabrakan dengan dinding; deteksi macet memilih target baru.
- **UI:** UnityEngine.UI.Text (legacy), bukan TextMeshPro.
- **Resource (2026-11-15):** `ResourceManager` (`Assets/Script/Resource/`) adalah satu-satunya penyimpan stok. Akses lewat `ResourceManager.Instance`: `Get`, `GetMax`, `Has`, `Add` (dibatasi kapasitas, mengembalikan jumlah yang masuk), `TryConsume` (false jika stok kurang). Event `OnResourceChanged(type, nilai, max)` untuk HUD. Tanpa `DontDestroyOnLoad` karena game satu scene. HabitatOxygen dan SuitOxygen terpisah. Belum dihubungkan ke sistem lain. [Repo, belum dites di Unity]
- **Waktu (2026-11-15):** `TimeManager` (`Assets/Script/Time/`) via `TimeManager.Instance`: `CurrentDay`, `TotalDays`, `RemainingSeconds`, `IsDayOver`, `IsPaused`, `StartDay(int)`; event `OnDayStarted(day)` dan `OnDayTimeEnded`. Timer TIDAK berhenti saat dialog terbuka (revisi 2026-11-15); flag Inspector `pauseDuringDialogue` (default mati) mengembalikan perilaku lama. `IsPaused` = `ExternalPause` (transisi tidur) atau, bila flag aktif, `DialogueUI.IsOpen`. Sistem yang mengikuti `IsPaused` (oksigen suit) ikut. Saat waktu habis timer berhenti di 0 dan event terpicu sekali; belum ada efek lain. [Repo, belum dites di Unity]
- **HUD (2026-11-15):** `HudUI` (`Assets/Script/UI/`) hanya tampilan: berlangganan `ResourceManager.OnResourceChanged` dan membaca `TimeManager`. Berlangganan di `Start` (bukan `OnEnable`) karena urutan Awake/OnEnable antar objek tidak terjamin. Menampilkan Food, Water, HabitatOxygen (label "Oxygen"), Energy. Dibuat lewat menu `Mars > Setup HUD and Time`, yang memakai helper `internal` dari `MarsUISetup`.
- **Skin HUD (2026-11-18):** `HudBar` (`Assets/Script/UI/`) hanya tampilan; `HudUI` memegang referensi bar opsional dan memanggil `SetFraction` dari event/refresh yang sudah ada (tanpa langganan baru). `MarsHudSkinSetup` (Editor) mengatur impor sprite dan membangun hierarki UI; tidak ada logika game. Sprite 9-slice memakai `Image.pixelsPerUnitMultiplier = 1/UiScale` (PPU sprite tetap 100 agar sama dengan sprite lain); isi bar bertipe Tiled di dalam `FillArea`. [Repo setelah patch, belum dites di Unity]
- **Tidur (2026-11-15):** `Bed` (`Assets/Script/Interaction/`, IInteractable) menjalankan coroutine: `Player.MovementEnabled=false`, `TimeManager.ExternalPause=true`, `FadeUI.FadeToBlack`, `TimeManager.StartDay(hari+1)`, pindah ke SpawnPoint, `FadeFromBlack`, buka kunci. `FadeUI` hanya tampilan (CanvasGroup, selalu sibling terakhir di Canvas). `Bed` tidak memegang state hari; state di TimeManager. Cooldown singkat setelah dialog mencegah dialog terbuka ulang (pola sama dengan TARS). Pesan Bed memakai `DialogueUI.Show` dengan pembicara "Sistem". [Repo, belum dites di Unity]

Angka oksigen suit tetap di `ResourceManager` (SuitOxygen); SuitSystem tidak menyimpan angkanya sendiri. Oksigen berkurang di `Update` selama dikenakan (di dalam maupun di luar, revisi GDD 2026-11-15) dan `TimeManager.IsPaused` false; `OnSuitOxygenEmpty` hanya dipicu bila kosong saat di luar. `IndoorZone` (trigger) memanggil `NotifyEnteredIndoor/NotifyExitedIndoor` (dihitung per zona). `SuitStation` (IInteractable) mengenakan, mengisi, atau melepas tergantung keadaan (prompt dinamis). `SuitGate` menyalakan/mematikan collider tembok dari `CanExit`/`IsOutdoors` dan tidak menyalakannya saat Player menumpuk dengan tembok. `HudUI` mendapat panel suit opsional. `SuitReminder` (dipasang pada objek SuitSystem) menampilkan dialog TARS via `DialogueUI.Show` bila suit dikenakan di dalam habitat terlalu lama (sementara pengganti TARSSystem). `Bed` memanggil `SuitSystem.Unequip()` setelah layar hitam. [Repo setelah patch, belum dites di Unity]
- **Hunger (2026-11-16):** `HungerSystem` (`Assets/Script/Survival/`, `HungerSystem.Instance`) menyimpan nilai kenyang sendiri (bukan di `ResourceManager`, agar array setting yang sudah diserialisasi di scene tidak perlu diubah). Kenyang berkurang di `Update` selama `TimeManager.IsPaused` false. `Feed()` menambah kenyang dan dipanggil `InventorySystem.UseDefault` saat pemain memakan kentang dari tas; event `OnSatietyChanged` dipakai `HudUI` dan `HungerReminder`. - **Tas dan storage (2026-11-16):** `InventorySystem` (`Assets/Script/Inventory/`, `InventorySystem.Instance`) memegang isi tas (`ItemType` Potato/Ice/Seed), pilihan slot, dan storage es/bibit; kentang di storage = `ResourceType.Food` di `ResourceManager` (event Food diteruskan sebagai `OnChanged`). `ResourceType.Ice` tidak dipakai gameplay lagi. Pemilihan aksi E ada di `InteractionDetector`: `IItemReceiver` (FarmingPlot, WaterPurifier) -> aksi bawaan item (`InventorySystem.CanUseDefault/UseDefault`) -> `IInteractable.Interact`; prompt dari `detector.CurrentPrompt`. `InventoryHotbarUI` dan `StorageUI` dibuat lewat kode di bawah Canvas (pola `WiringMinigameUI`); `StorageUI.IsOpen` (static) dibaca detector dan InventorySystem untuk memblokir input, dan mengunci `PlayerMovement.MovementEnabled`. Tombol slot memakai `Input.GetKeyDown` (Input Manager lama, sama seperti kode input yang ada). [Repo setelah patch, belum dites di Unity]
- **HP (2026-11-27):** `HealthSystem` (`Assets/Script/Survival/`, `HealthSystem.Instance`) menyimpan HP sendiri. - **Objek interaktif (2026-11-15, patch ini):** semua `IInteractable`, mencari referensi lewat `FindFirstObjectByType` di `Start`, memberi pesan lewat `DialogueUI.Show` (pola sama dengan `SuitStation`), dan membaca/mengubah stok hanya lewat `ResourceManager.Instance`. Aturan umum: (1) mesin dan tanaman ikut `TimeManager.IsPaused`; (2) logika dipisah dari tampilan: status lewat properti/event (`WaterPurifier.OnProcessingChanged`, `OxygenGenerator.OnRunningChanged`, `SolarPanel.OnDamagedChanged`) dan indikator opsional (`activeIndicator`, sprite/warna); (3) `FarmingPlot` berlangganan `TimeManager.OnDayStarted` di `Start` (tanaman yang disiram maju satu tahap saat Bed memulai hari baru); (4) `SolarPanel` menambah Energy tiap `tickSeconds` (bukan tiap frame) agar event HUD tidak berlebihan, banyak panel saling menjumlah; (5) `OxygenGenerator` bekerja otomatis per siklus dan punya saklar E (USULAN); (6) `WaterPurifier.StatusText`/`OxygenGenerator.StatusText`, `SolarPanel.IsDamaged`/`CurrentEnergyPerSecond`, dan `HungerSystem` tetap dibuka sebagai properti baca-saja untuk `TARSSystem`; (7) `RepairPoint` memperbaiki langsung sebagai pengganti sementara minigame kabel. `HudUI` mendapat `iceText` opsional. - **Kerusakan panel dan minigame kabel (2026-11-16, Milestone 10):** `SolarPanelDamageScheduler` (`Assets/Script/Outdoor/`) berlangganan `TimeManager.OnDayStarted` di `Start` dan menjadwalkan SATU waktu acak per hari (dihitung dari `DayDurationSeconds - RemainingSeconds`, hanya maju saat `!IsPaused`); saat tercapai memanggil `SolarPanel.Damage()` pada satu panel normal acak, lalu mengumumkan lewat `DialogueUI` (menunggu dialog/minigame lain tertutup). `WiringMinigameUI` (`Assets/Script/UI/`) dipasang di Canvas, membangun UI-nya lewat kode di `Awake`, memakai polling `Input.mousePosition`/`GetMouseButton*` (API lama, aman di mode Both) dan `RectTransformUtility` untuk hit-test, bukan handler EventSystem. `Open(nama, onSuccess, onCancel)` mengatur `TimeManager.ExternalPause` dan `PlayerMovement.MovementEnabled` lalu memulihkan nilai sebelumnya saat tutup. `RepairPoint` hanya memanggil `Open` dan `SolarPanel.Repair()` di callback sukses; minigame tidak mengetahui `SolarPanel`. [Repo setelah patch, belum dites di Unity]
- **TARSSystem (2026-11-17, Milestone 11):** `TARSSystem` (`Assets/Script/TARS/`, `TARSSystem.Instance`) adalah satu-satunya pemilik waktu tampil pesan TARS. `Announce(key, Priority, Func<string[]>, Func<bool> isStillValid)` mengantrekan pesan; teks dibuat saat tampil (angka terbaru) dan pesan dibuang bila `isStillValid` false (masalah sudah teratasi) atau kedaluwarsa (non-Critical). Pesan tampil hanya bila `DialogueUI` tertutup, `StorageUI` tertutup, dan `TimeManager.ExternalPause` false (tidur/minigame), dengan jeda antar pesan dan cooldown per kunci. Pemantau berlangganan di `Start`: `ResourceManager.OnResourceChanged` (tingkat 0-3 per resource, tiap tingkat diumumkan sekali per penurunan), `SuitSystem.OnEquippedChanged`, `SolarPanel.OnDamagedChanged` (panel yang ada saat Start), `TimeManager.OnDayStarted/OnDayTimeEnded`. Pemanggil lain: `HungerReminder` (antrean TARS), `SolarPanelDamageScheduler` (tidak mengumumkan sendiri bila `TARSSystem` ada). `BuildConversationLines` dipanggil `TarsWanderer.Interact` untuk laporan. Kemungkinan tabrakan: `SuitGate`, `SuitStation`, dan mesin masih memanggil `DialogueUI` langsung. Panel yang dibuat saat runtime tidak dipantau. [Repo setelah patch, belum dites di Unity]
- **Tutorial Day 1 (2026-11-17):** `TutorialManager` (`Assets/Script/Tutorial/`, `TutorialManager.Instance`) hanya MEMBACA keadaan sistem lain dan tidak mengubah resource. Daftar langkah (`TutorialStepData[]` di Inspector; urutan = urutan array, bukan nilai `TutorialStepId`; ID tersimpan di scene sebagai angka sehingga ID baru ditambah di akhir enum), langkah aktif, event `OnStepStarted/OnStepCompleted/OnTutorialFinished`. Syarat tiap langkah dikunci di `HashSet` begitu terpenuhi (kapan pun), lalu langkah yang sudah terpenuhi dilewati saat gilirannya (urutan bebas, bukan quest). Sumber syarat: event (`IceDeposit.OnCollected` dihitung sampai `iceToCollect` atau tas es penuh, `WaterPurifier.OnProcessingChanged`, `TarsWanderer.OnPlayerTalked`, `SuitSystem.OnEquippedChanged` untuk langkah RemoveSuit) dan polling tiap 0,25 dtk (`SuitSystem.IsEquipped`, `StorageUI.IsOpen`, `FarmingPlot.HasPlant/IsWatered`, `InteractionDetector.CurrentTarget is OxygenGenerator`); Sleep lewat `TimeManager.OnDayStarted`. Arahan lewat `TARSSystem.Announce("tutorial.<id>", Warning, ...)` dengan `isStillValid` = langkah masih berjalan, diulang tiap `reminderSeconds`. `TryCompleteStep(id)` dapat dipanggil sistem lain. Status selesai di `PlayerPrefs` (`Mars.TutorialCompleted`, USULAN sampai SaveSystem ada); `skipKey` (Tab) melewati bila pernah selesai. Objek yang dicari lewat `FindObjectsByType` hanya saat Start (objek yang dibuat saat runtime tidak dipantau). [Repo setelah patch, belum dites di Unity]

[Repo setelah patch, belum dites di Unity]
